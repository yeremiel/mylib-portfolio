# design — 設計の抜粋

バックエンド（Go）の設計ドキュメントのうち、認証・セッション・不正利用対策に関わる部分の抜粋です。
サービスの内部構成（データベースのコレクション名、ドメイン別の詳細など）は、省略または一般化しています。

| 場所 | 内容 |
|---|---|
| [`security-and-auth.md`](security-and-auth.md) | リクエストの処理構造、トークンとセッション、再認証、退会（即時削除と冪等性）、ログイン対象のレートリミットとそのトレードオフ |
| [`auth-api-excerpt.md`](auth-api-excerpt.md) | Auth API ドキュメントの抜粋（トークン更新、再認証のヘッダー規約、退会、レートリミット） |
