# samples/go — 動作する Go コードの抜粋

MyLib のバックエンドの共通パッケージから、サービスのコアロジックに依存しない部分だけを切り出したものです。単体でビルド・テストできます。

```bash
cd samples/go
go vet ./...
go test ./...
```

| パッケージ | 内容 |
|---|---|
| `pkg/utils` | JWT（アクセス／リフレッシュトークンの発行と検証）、パスワードのハッシュ、安全なトークンと OTP の生成、API レスポンスエンベロープ |
| `pkg/i18n` | go-i18n を使った多言語メッセージ（サンプルとして、認証系のメッセージのみを同梱） |
| `pkg/logger` | zap を使った構造化ログとファイルローテーション |

## 元のコードからの変更点

- コメントとエラーメッセージを、日本語・韓国語から英語に翻訳しています（ロジックは変更していません）。
- i18n のメッセージリソースは、認証・共通・ヘルスチェックの分のみに絞っています（韓国語のリソースは、実際の多言語対応のデータとして残しています）。
- Go のモジュール名を、このリポジトリ用に変更しています。
