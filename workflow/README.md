# workflow — AIエージェントとの進め方

AIエージェントをチームメンバーとして運用するための、指示書と作業の記録です。いずれも韓国語の原文から、判断の経緯が読み取れる部分を日本語に翻訳した抜粋です。

| 場所 | 内容 |
|---|---|
| [`agent-instructions/`](agent-instructions/) | エージェントが作業の前に読む指示書（ワークスペース、バックエンド、Flutter）。ドキュメントの寿命、読む順序、API 連携、認証・セキュリティの規則 |
| [`process/history-excerpt.md`](process/history-excerpt.md) | 終わった計画・やめた計画の記録の抜粋（判断の経緯） |
| [`process/readiness-review-structure.md`](process/readiness-review-structure.md) | 製品化の準備度を、段階ごとの開始条件・完了条件で判定する仕組み |
